Why the QR keeps changing
Every 20 seconds the prototype generates a fresh signed token containing the pass ID, route, validity window and rolling time-window number. The rotating token helps reduce screenshot-based misuse while the live pass continues producing refreshed tokens without a network connection.

Why offline verification works
The conductor app can verify a pass locally without a live network connection. It uses the issuer's public verification key and a periodically-synced revocation list. A scan checks the signature, validity window, and revocation status on-device. In this prototype, HMAC-SHA256 is only a demonstration stand-in; a production implementation would use the planned Ed25519 asymmetric signature scheme.
